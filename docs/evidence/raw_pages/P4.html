Playerduo by Duc Nguyen

1. Dịch vụ trung gian kết nối game thủ với proplayer/idol/streamer

1.1. User lựa chọn Player -> thanh toán phí thuê -> kết nối với player qua phòng chat -> Player nhận được thông báo qua tin nhắn trên web và sms -> Player Accept -> 2 bên tụ thỏa thuận cách thức chơi -> tạo game để chơi

2. Cung cấp giải pháp thanh toán

3. Chế độ đánh giá dành cho user và player

4. Cắt phí 10%/giao dịch thành công
